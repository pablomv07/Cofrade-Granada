# ✝️ Cofrade Granada

**Cofrade Granada** es una aplicación web dedicada a la Semana Santa de Granada. Su objetivo es reunir en un mismo lugar información útil para los cofrades y facilitar la organización de cada jornada.

## 🌟 Características principales

- 📅 **Agenda:** consulta los horarios y las salidas procesionales.
- 🗺️ **Mapa interactivo:** visualiza los recorridos de las hermandades.
- ⭐ **Favoritos:** guarda tus hermandades preferidas.
- 🗓️ **Mi plan:** organiza tu propia Semana Santa.
- 🪪 **Pasaporte Cofrade:** registra las hermandades que has visto.
- 🎯 **Trivial cofrade:** demuestra cuánto sabes sobre la Semana Santa.
- 📔 **Diario cofrade:** guarda tus recuerdos y experiencias.
- 📖 **Glosario:** descubre términos del mundo cofrade.
- 🌙 **Modo oscuro:** adapta la aplicación a tus preferencias.
- 📲 **PWA:** instala la aplicación en dispositivos compatibles.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Leaflet
- OpenStreetMap
- Service Workers

## 📱 Acceso

La aplicación está diseñada para utilizarse tanto desde ordenadores como desde dispositivos móviles.
